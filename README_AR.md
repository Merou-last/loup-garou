# 🐺 Loup-Garou Discord Bot — النسخة 2 (لعبة تلقائية كاملة)

## ما الذي تغيّر؟
اللعبة الآن تدير نفسها: ليل ← قدرات الأدوار ← فجر ← نقاش ← تصويت سري ← إقصاء ← فحص الفوز، وتتكرر حتى تنتهي.
- **10 أدوار مفعّلة بالكامل:** الذئب، القروي، العرافة، الطبيب، الصياد، الحارس، الساحرة، الطفلة، العمدة، الذئب الأبيض.
- **عرين الذئاب:** قناة نصية خاصة تُنشأ لكل جولة وتُحذف بعدها.
- **كتم تلقائي** للجميع ليلًا وللموتى دائمًا، وفكّه نهارًا (حتى لمن يدخل الصوت متأخرًا).
- **تصويت سري** بالأزرار مع عدّ تلقائي (العمدة بصوتين، التعادل = لا إقصاء).
- **خبرة ومستويات دائمة** في SQLite، `/rank` و`/top`.
- الأزرار تعمل حتى لو كانت رسائل الخاص مغلقة.

## 1) إنشاء البوت
1. https://discord.com/developers/applications ← **New Application** ← **Bot** ← انسخ **Token**.
2. **Bot ← Privileged Gateway Intents ← فعّل `Server Members Intent`** (إلزامي، وإلا لن يعمل).
3. **OAuth2 ← URL Generator:** `bot` + `applications.commands`، والصلاحيات:
   `View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Manage Channels, Manage Roles, Mute Members, Connect, Speak`.
4. ادعُ البوت، ثم **ارفع رتبته فوق رتب اللاعبين ورولات المستويات** من إعدادات السيرفر.

## 2) التشغيل على جهازك
```
python -m venv .venv
.venv\Scripts\activate          (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          (ثم ضع التوكن)
python bot.py
```
- **FFmpeg و libopus اختياريان:** بدونهما تعمل اللعبة والكتم كاملين، وتغيب المؤثرات الصوتية فقط.
  Ubuntu/Debian: `sudo apt install ffmpeg libopus0` — Termux: `pkg install ffmpeg opus`.
- الصوت يتطلب مكتبة `davey` (تُثبَّت تلقائيًا مع `discord.py[voice]` الإصدار 2.7+) لأن Discord فرض التشفير DAVE على المكالمات.

## 3) الاستضافة المجانية (الأهم)
البوت يحتاج أن يكون **شغّالًا وقت اللعب فقط**، لذلك أبسط حل مجاني فعلًا هو تشغيله على حاسوبك أو هاتفك (Termux) أو Raspberry Pi وقت الجولات.
للتشغيل 24/7 مجانًا:
| الخيار | ملاحظات |
|---|---|
| **لوحات استضافة بوتات مجانية** (مثل bot-hosting.net، Wispbyte، pella، Quaxly) | بلا بطاقة. بعضها يتطلب «تجديدًا» دوريًا من اللوحة (bot-hosting.net كل 4 أيام). ارفع الملفات، ثبّت `requirements.txt`، وضع `DISCORD_TOKEN` في متغيرات البيئة، وشغّل `python bot.py`. |
| **Oracle Cloud Always Free** | خادم حقيقي دائم، لكن التسجيل يطلب عادةً بطاقة للتحقق فقط. استخدم `Dockerfile` أو systemd. |
- ملف `Dockerfile` جاهز لأي استضافة تدعم Docker (يثبّت FFmpeg وopus).
- إن طلبت الاستضافة منفذًا (PORT) سيشغّل البوت خادم صحة صغيرًا تلقائيًا.
- احفظ مجلد `data/` (قاعدة الخبرة). إن كانت الاستضافة تمسح الملفات عند كل تشغيل ستضيع النقاط فقط، واللعبة تعمل.
- هذه مواقع طرف ثالث وشروطها تتغيّر؛ راجع صفحة كل واحد قبل الاعتماد عليه.
- تجنّب الاستضافات التي «تنام» عند الخمول، فالبوت يحتاج اتصالًا دائمًا.

## 3-ب) النشر على MongoDB Atlas + Render (خطوة بخطوة)
**أ. قاعدة البيانات (MongoDB Atlas، الخطة المجانية M0)**
1. أنشئ Cluster مجانيًا (M0) ثم **Database Access ← Add User** (اسم مستخدم وكلمة مرور؛ تجنّب الرموز الخاصة أو رمّزها URL-encode).
2. **Network Access ← Add IP Address ← Allow access from anywhere (`0.0.0.0/0`)**، لأن Render المجاني ليس له IP ثابت.
3. **Connect ← Drivers** وانسخ الرابط `mongodb+srv://USER:PASS@cluster.../` وهذا هو `MONGODB_URI`.
   عند وجوده يحفظ البوت الخبرة والمدير في MongoDB تلقائيًا (مجموعتا `stats` و`settings`)، وإن فشل الاتصال يرجع إلى SQLite ويكتب السبب في السجل.

**ب. Render**
1. ارفع مجلد المشروع إلى مستودع GitHub (الملف `.env` لا يُرفع؛ هو مستثنى في `.gitignore`).
2. في Render: **New ← Blueprint** واختر المستودع (يقرأ `render.yaml`)، أو **New ← Web Service ← Docker** يدويًا بخطة **Free**.
3. أضف متغيرات البيئة: `DISCORD_TOKEN` و`MONGODB_URI` و`GUILD_ID` (اختياري). المتغير `DISABLE_AUDIO=1` موجود في الملف ويُنصح به على الخطة المجانية لضعف المعالج.
4. بعد النشر راقب **Logs**: يجب أن ترى «متصل بـ MongoDB» ثم «Logged in as ...».

**ج. مشكلة النوم على Render المجاني (مهم)**
الخدمة المجانية تنام بعد 15 دقيقة بلا طلبات واردة، والاتصال الصادر للبوت مع Discord لا يُحسب طلبًا. لذلك:
- **الأفضل لبوت ألعاب:** افتح رابط الخدمة `https://اسمك.onrender.com` في المتصفح قبل اللعب بدقيقتين لإيقاظه، ودعه ينام بعد انتهائكم.
- **للتشغيل المستمر:** اجعل UptimeRobot (مجاني) يزور الرابط كل 5 دقائق. يستهلك نحو 720 من الساعات المجانية الشهرية (الحد 750 لخدمة واحدة)، وهو يحتمل الإيقاف إذا غيّرت Render سياستها.
- إعادة التشغيل أو النوم أثناء جولة تُنهيها (حالة الجولة في الذاكرة)، أما النقاط فمحفوظة في MongoDB.

## 4) طريقة اللعب
1. المدير: `/setup` مرة واحدة ثم `/setmanager`.
2. المدير ينشر واجهة الأزرار باستخدام `/lobby`؛ يمكن للاعبين الانضمام/الانسحاب/تحديث القائمة من اللوحة. الحد 25 لاعبًا.
3. المدير (أو لاعب بمستوى 5): `/start`. تصل البطاقات في الخاص، أو زر «اعرض دوري».
4. **كل ليلة اضغط الجميع زر «افتح قدرتك الليلية»** (حتى من لا قدرة له، حتى لا تُكشف الأدوار).
5. ثم النقاش والتصويت تلقائيًا. `/skip` يتخطى المرحلة، `/stop` يوقف الجولة.

| العدد | الأدوار |
|---|---|
| 5–6 | ذئب، عرافة، طبيب، قرويون |
| 7 | + صياد |
| 8 | + ساحرة (وذئب ثانٍ) |
| 9 | + حارس |
| 10 | + طفلة |
| 11 | + عمدة |
| 12+ | + ذئب أبيض |

## واجهة النقاش والصوت
- عند بدء الجولة، تُغلق الكتابة في غرفة اللعبة ويُمنع دخول أعضاء جدد إلى قناة الصوت مع السماح للاعبي الجولة. عند النهاية تعود صلاحيات القنوات.: يرفع كتم لاعب واحد ويكتم بقية اللاعبين الأحياء في قناة الصوت، ثم ينتقل إلى اللاعب التالي كل 20 ثانية.
- زر «طلب دور إضافي للكلام» يضيف اللاعب إلى قائمة الانتظار؛ العمدة الحي يضغط «لوحة العمدة: الموافقة على طلب» للموافقة على الطلب الأقدم.
- عند بدء الجولة تُغلق الكتابة في غرفة اللعبة ويُمنع دخول متفرجين جدد إلى قناة الصوت، مع السماح للاعبين المسجلين. عند النهاية يعيد البوت صلاحيات الدخول والكتابة إلى الوراثة.

## 7) حدود معروفة
حالة الجولة الجارية في الذاكرة (إعادة تشغيل البوت وسط جولة تُنهيها، وعند الإقلاع يفك البوت كتم قناة القرية). الذئب الأبيض يفوز منفردًا فقط إن بقي آخر لاعب حي؛ غير ذلك يُحسب فوزًا للذئاب.
للتطوير والاختبار: `python -m unittest discover -s tests` و`python tests/sim_game.py` (محاكاة جولات كاملة بدون Discord).


## ميزة تمييز اللاعب الميت (جديدة)
- عند خروج لاعب من الجولة، يغيّر البوت لقبه مؤقتًا إلى `💀 DEAD | السبب`، مثل `💀 DEAD | التصويت` أو `💀 DEAD | الذئاب`.
- ينشر البوت أيضًا رسالة في قناة اللعبة توضح كيف مات اللاعب ودوره.

- يجب تفعيل صلاحية `Manage Nicknames` للبوت، ويجب أن تكون رتبة البوت أعلى من رتب اللاعبين الذين تريد تغيير ألقابهم. قد يفشل التغيير إذا كانت صلاحيات Discord لا تسمح بذلك.

## 8) واجهة Merou Last على Blogger (جديدة)
المجلد `merou_last_blogger/` يحتوي على قالب Blogger فاخر بالعربية، ولوحة بديلة HTML، وتعليمات الربط. بعد رفع تحديث البوت إلى GitHub ونشره على Render، افتح `merou_last_blogger/README_AR.md` واتبع خطوات تعديل `API_BASE` و`GUILD_ID` ورابط دعوة Discord.

الـ API العام للقراءة فقط:
- `/api/public/status?guild_id=ID` حالة الجولة.
- `/api/public/leaderboard?guild_id=ID&limit=10` ترتيب اللاعبين.
- `/api/public/roles` موسوعة الأدوار.
- `/assets/cards/werewolf.png` صور البطاقات.

لا تضع `DISCORD_TOKEN` أو `MONGODB_URI` داخل قالب Blogger. لا توجد واجهة ويب لتغيير حالة اللعبة؛ جميع أوامر الإدارة تبقى داخل Discord لحماية السيرفر.
