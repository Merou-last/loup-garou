# 🐺 Loup-Garou Discord Bot — النسخة 2 (لعبة تلقائية كاملة)

## ما الذي تغيّر؟
اللعبة الآن تدير نفسها: ليل ← قدرات الأدوار ← فجر ← نقاش ← تصويت سري ← إقصاء ← فحص الفوز، وتتكرر حتى تنتهي.
- **10 أدوار مفعّلة بالكامل:** الذئب، القروي، العرافة، الطبيب، الصياد، الحارس، الساحرة، الطفلة، العمدة، الذئب الأبيض.
- **عرين الذئاب:** قناة نصية خاصة تُنشأ لكل جولة وتُحذف بعدها.
- **كتم تلقائي** للجميع ليلًا وللموتى دائمًا، وفكّه نهارًا (حتى لمن يدخل الصوت متأخرًا).
- **تصويت سري** بالأزرار مع عدّ تلقائي (العمدة بصوتين، التعادل = لا إقصاء).
- **خبرة ومستويات دائمة** في SQLite، `/rank` و`/top`.
- الأزرار تعمل حتى لو كانت رسائل الخاص مغلقة.

## 1) إنشاء البوت
1. https://discord.com/developers/applications ← **New Application** ← **Bot** ← انسخ **Token**.
2. **Bot ← Privileged Gateway Intents ← فعّل `Server Members Intent`** (إلزامي، وإلا لن يعمل).
3. **OAuth2 ← URL Generator:** `bot` + `applications.commands`، والصلاحيات:
   `View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Manage Channels, Manage Roles, Mute Members, Connect, Speak`.
4. ادعُ البوت، ثم **ارفع رتبته فوق رتب اللاعبين ورولات المستويات** من إعدادات السيرفر.

## 2) التشغيل على جهازك
```
python -m venv .venv
.venv\Scripts\activate          (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          (ثم ضع التوكن)
python bot.py
```
- **FFmpeg و libopus اختياريان:** بدونهما تعمل اللعبة والكتم كاملين، وتغيب المؤثرات الصوتية فقط.
  Ubuntu/Debian: `sudo apt install ffmpeg libopus0` — Termux: `pkg install ffmpeg opus`.
- الصوت يتطلب مكتبة `davey` (تُثبَّت تلقائيًا مع `discord.py[voice]` الإصدار 2.7+) لأن Discord فرض التشفير DAVE على المكالمات.

## 3) الاستضافة المجانية (الأهم)
البوت يحتاج أن يكون **شغّالًا وقت اللعب فقط**، لذلك أبسط حل مجاني فعلًا هو تشغيله على حاسوبك أو هاتفك (Termux) أو Raspberry Pi وقت الجولات.
للتشغيل 24/7 مجانًا:
| الخيار | ملاحظات |
|---|---|
| **لوحات استضافة بوتات مجانية** (مثل bot-hosting.net، Wispbyte، pella، Quaxly) | بلا بطاقة. بعضها يتطلب «تجديدًا» دوريًا من اللوحة (bot-hosting.net كل 4 أيام). ارفع الملفات، ثبّت `requirements.txt`، وضع `DISCORD_TOKEN` في متغيرات البيئة، وشغّل `python bot.py`. |
| **Oracle Cloud Always Free** | خادم حقيقي دائم، لكن التسجيل يطلب عادةً بطاقة للتحقق فقط. استخدم `Dockerfile` أو systemd. |
- ملف `Dockerfile` جاهز لأي استضافة تدعم Docker (يثبّت FFmpeg وopus).
- إن طلبت الاستضافة منفذًا (PORT) سيشغّل البوت خادم صحة صغيرًا تلقائيًا.
- احفظ مجلد `data/` (قاعدة الخبرة). إن كانت الاستضافة تمسح الملفات عند كل تشغيل ستضيع النقاط فقط، واللعبة تعمل.
- هذه مواقع طرف ثالث وشروطها تتغيّر؛ راجع صفحة كل واحد قبل الاعتماد عليه.
- تجنّب الاستضافات التي «تنام» عند الخمول، فالبوت يحتاج اتصالًا دائمًا.

## 4) طريقة اللعب
1. المدير: `/setup` مرة واحدة ثم `/setmanager`.
2. اللاعبون: `/join` (5 على الأقل، 25 كحد أقصى) ويدخلون قناة **🔊・قرية-الصوت**.
3. المدير (أو لاعب بمستوى 5): `/start`. تصل البطاقات في الخاص، أو زر «اعرض دوري».
4. **كل ليلة اضغط الجميع زر «افتح قدرتك الليلية»** (حتى من لا قدرة له، حتى لا تُكشف الأدوار).
5. ثم النقاش والتصويت تلقائيًا. `/skip` يتخطى المرحلة، `/stop` يوقف الجولة.

| العدد | الأدوار |
|---|---|
| 5–6 | ذئب، عرافة، طبيب، قرويون |
| 7 | + صياد |
| 8 | + ساحرة (وذئب ثانٍ) |
| 9 | + حارس |
| 10 | + طفلة |
| 11 | + عمدة |
| 12+ | + ذئب أبيض |

## 5) الأوامر
`/setup` `/setmanager` `/join` `/leave` `/start` `/skip` `/stop` `/connect` `/vote` `/status` `/roles` `/rank` `/top` `/help_lg`

## 6) حل المشاكل
| المشكلة | الحل |
|---|---|
| يتوقف فورًا برسالة Intents | فعّل Server Members Intent |
| لا تظهر الأوامر | تأكد من `GUILD_ID` الصحيح أو انتظر المزامنة العامة، وأن البوت مدعو بـ `applications.commands` |
| «تعذّر كتم أعضاء» | امنح البوت Mute Members وارفع رتبته |
| لا تتحدّث رولات المستوى | ارفع رتبة البوت فوق رولات المستويات |
| لا صوت | ثبّت FFmpeg وlibopus (اللعبة تعمل بدونهما) |
| عرين الذئاب لا يُنشأ | يحتاج Manage Channels (اللعبة تعمل بدونه) |

## 7) حدود معروفة
حالة الجولة الجارية في الذاكرة (إعادة تشغيل البوت وسط جولة تُنهيها، وعند الإقلاع يفك البوت كتم قناة القرية). الذئب الأبيض يفوز منفردًا فقط إن بقي آخر لاعب حي؛ غير ذلك يُحسب فوزًا للذئاب.
للتطوير والاختبار: `python -m unittest discover -s tests` و`python tests/sim_game.py` (محاكاة جولات كاملة بدون Discord).
